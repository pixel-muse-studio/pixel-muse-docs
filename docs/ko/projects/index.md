# 프로젝트

Pixel Muse Studio에서 제공하는 프로젝트와 문서를 한곳에서 확인할 수 있습니다.

## PMdurability

CraftEngine 아이템에 원하는 최대 내구도와 색상 게이지를 적용합니다. 수리, 제작 도구, 음식 사용과 외부 API 연동도 지원합니다.

- 상태: **개발 및 테스트 중**
- 현재 문서 버전: **2.4.0**
- 연동: CraftEngine, PlaceholderAPI, Skript, Nexo

[PMdurability 문서 열기 →](/ko/pmdurability/)

## 문서 구성

프로젝트마다 설치, 설정, 예제와 API 문서를 나누어 제공합니다.

```text
프로젝트
├─ PMdurability
│  ├─ 설치 및 시작
│  ├─ 설정
│  ├─ 예제
│  └─ 명령어 · API
└─ PMfishing (추가 예정)
```

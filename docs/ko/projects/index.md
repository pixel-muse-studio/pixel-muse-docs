# 프로젝트

Pixel Muse Studio의 프로젝트를 한곳에서 확인할 수 있습니다.

## PMdurability

CraftEngine 아이템에 자유로운 최대 내구도, 색상 게이지, 수리·제작·음식 사용과 외부 API 연동을 추가합니다.

- 상태: **개발 및 테스트 중**
- 현재 문서 버전: **2.4.0**
- 연동: CraftEngine, PlaceholderAPI, Skript, Nexo

[PMdurability 문서 열기 →](/ko/pmdurability/)

## 다음 프로젝트 추가 방식

새 프로젝트는 이 목록에 카드처럼 추가하고, 좌측 메뉴에 독립된 문서 묶음을 생성합니다.

```text
프로젝트
├─ PMdurability
│  ├─ 설치 및 시작
│  ├─ 설정
│  ├─ 예제
│  └─ 명령어 · API
└─ PMfishing (추가 예정)
```

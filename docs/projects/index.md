## PMdurability

Adds flexible maximum durability, colored inventory gauges, food and crafting-tool usage, repairs, and integration APIs to CraftEngine items.

- Status: **Development and testing**
- Documentation version: **2.4.0**
- Integrations: CraftEngine, PlaceholderAPI, Skript, Nexo
